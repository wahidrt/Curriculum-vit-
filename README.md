## Compilation

Chaque CV utilise `moderncv` et est conçu pour tenir sur une seule page A4.

Exemple :

```bash
cd Quant_Analyst
pdflatex CV_Quant_Analyst.tex
```

Les versions ont été structurées pour mettre en avant des compétences et projets différents selon le métier visé, plutôt que de simplement changer le titre du CV.
